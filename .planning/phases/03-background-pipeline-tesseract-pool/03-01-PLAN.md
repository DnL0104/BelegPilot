## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `/hangfire` | Untrusted cookie value crosses here. Cookie value is treated as a JWT and must be cryptographically validated before any dashboard render. |
| browser → `/auth/login` `/auth/refresh` `/auth/logout` | Endpoints that mint or clear the cookie; must use `Secure=true` so cookies don't leak over plain HTTP. |
| API process → Postgres (Hangfire schema) | Hangfire serializes job arguments to JSON in `hangfire.job.arguments`. Argument tampering requires Postgres compromise (same as the rest of the app — outside Phase 3 threat scope). |
| API startup → env var `Hangfire__SeedAdminEmails` | Single-direction trust: the env carries identity-promotion data. Operator-supplied; visible in `docker-compose.yml`. Not secret-grade. |

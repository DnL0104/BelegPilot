## Operator Actions (HUMAN-UAT — Blocking before commercial launch)

These steps cannot be automated. The operator must perform them and record results in the "Search Results" table above.

**Step 1 — DPMA search (Germany):**
1. Go to DPMAregister: https://register.dpma.de/DPMAregister/marke/einsteiger
2. Search for the mark "TaxReader" (use both "TaxReader" exact and "Tax Reader" with space).
3. Filter by Nizza class 9 and repeat for class 42.
4. Screenshot the results page (even if no results — the screenshot IS the evidence).
5. Note any identical or confusingly similar marks (same or related classes, identical or phonetically similar name).
6. Record the search date and result in the table above.

**Step 2 — EUIPO search (EU-wide):**
1. Go to EUIPO eSearch+: https://euipo.europa.eu/eSearch/
2. Search for "TaxReader" in the trade mark search.
3. Filter by Nice class 9 and repeat for class 42.
4. Screenshot the results page.
5. Note any identical or confusingly similar EU trade marks.
6. Record the search date and result in the table above.

**Step 3 — Record evidence:**
- Save screenshots as files (e.g., `dpma-class9-YYYY-MM-DD.png`, `euipo-class42-YYYY-MM-DD.png`).
- Store in a legal/IP folder accessible to the operator.
- Reference the evidence files in the "Evidence" column of the search results table.

**Step 4 — Make the decision:**
- If ALL results are `Clear`: set Decision = `proceed` (or `register` if proactive filing is desired).
- If ANY result is `Conflicted`: set Decision = `rename`. DO NOT proceed to commercial launch. Open a separate rename decision record.
- Update the "Decision" section above.

**Step 5 — Optional — proactive trademark filing:**
- If Decision = `register`, engage a German trademark attorney (Markenanwalt) to file a national DE trademark with DPMA and/or an EU trademark (EUTM) with EUIPO.
- A registered trademark provides stronger protection against future infringement than an unregistered mark.

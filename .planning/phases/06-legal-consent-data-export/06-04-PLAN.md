## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → /export/download | Token-bearing request must prove ownership before any bytes stream |
| Hangfire job → /tmp/exports | Server-only file write; bundle scoped strictly to one user's data |
| export bundle contents → user | Bundle must exclude secrets (password hash) and other users' rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-40 | Information Disclosure | IDOR — downloading another user's bundle | mitigate | Download endpoint is RequireAuthorization (no AllowAnonymous) + compares `rec.UserId != currentUser.UserId` → 403; ExportDownloadEndpointTests asserts 403 on mismatch; UAT step 5 |
| T-06-41 | Information Disclosure | Token guessing / enumeration | mitigate | Token = `Guid.NewGuid().ToString("N")` (128-bit CSPRNG, opaque) — Security Domain V6; not sequential; status endpoint returns "Expired" for non-owned tokens (no existence leak) |
| T-06-42 | Information Disclosure | Token replay after download | mitigate | One-time: `tokenStore.Invalidate(token)` after streaming; second download → 404; UAT step 6 |
| T-06-43 | Information Disclosure | Stale bundle leakage past purge window | mitigate | ExportCleanupJob deletes *.zip older than 24h daily; token TryGet flips to Expired past ExpiresAtUtc; ExportCleanupJobTests asserts purge |
| T-06-44 | Information Disclosure | Password hash / internal fields in bundle | mitigate | Export projects explicit DTO shapes excluding PasswordHash; acceptance_criteria + ExportUserDataJobTests assert no PasswordHash entry; UAT step 3 |
| T-06-45 | Information Disclosure | Path traversal via token→file mapping | mitigate | Token is hex-only `Guid.ToString("N")`; file path is `Path.Combine(tmp, token + ".zip")` with no user-supplied path segments; token validated against store before file access |
| T-06-46 | Tampering | Cross-user audit rows in bundle | mitigate | Audit query filters `SubjectUserId == userId`; ExportUserDataJobTests asserts a second user's row is excluded; UAT step 4 |
</threat_model>

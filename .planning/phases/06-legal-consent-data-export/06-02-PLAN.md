## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser localStorage → Sentry SDK init | Consent state in localStorage gates whether the Sentry SDK is allowed to capture/send events |
| pre-hydration instrumentation-client → React ConsentProvider | Two code paths both gate Sentry; must not double-init or bypass consent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-20 | Information Disclosure | Sentry sends telemetry before consent (TTDSG/privacy violation) | mitigate | Sentry.init guarded by `NEXT_PUBLIC_SENTRY_ENABLED && hasSentryConsent()` in instrumentation-client (pre-hydration) AND `Sentry.isInitialized()` guard in provider grant path; acceptance_criteria assert both |
| T-06-21 | Repudiation | Pre-ticked consent checkbox manufactures false consent (TTDSG) | mitigate | Fehleranalyse defaults to false on fresh visit; acceptance_criteria assert no pre-check; manual UAT step 2 |
| T-06-22 | Tampering | Revoke fails to stop telemetry (consent ignored) | mitigate | revokeSentry() calls `Sentry.close(2000)` which flushes + disables; manual UAT step 4 verifies no further events |
| T-06-23 | Elevation of Privilege | Essential auth cookies exposed to opt-out, breaking session security | accept | "Notwendig" category is disabled/always-on; auth cookies are never gated by consent toggles (D-08) |
</threat_model>

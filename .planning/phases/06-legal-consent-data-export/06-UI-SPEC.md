## Interaction Contracts

### Cookie Banner

| Trigger | Action |
|---------|--------|
| First page load, `decided === false` | Banner renders fixed bottom, visible |
| "Alle akzeptieren" clicked | Sets `{ notwendig: true, fehleranalyse: true, decided: true }` in localStorage → calls `grantSentry()` if env-enabled + not already initialized → hides banner |
| "Nur notwendige" clicked | Sets `{ notwendig: true, fehleranalyse: false, decided: true }` → hides banner |
| "Einstellungen" clicked | Opens `ConsentSettingsDialog` |
| Footer "Cookie-Einstellungen" clicked | Sets `settingsPanelOpen = true` → opens `ConsentSettingsDialog` |
| ConsentSettingsDialog "Einstellungen speichern" | Writes updated state → calls `grantSentry()` or `revokeSentry()` as appropriate → closes dialog |
| Consent revoke ("Fehleranalyse" unchecked + saved) | Calls `await Sentry.close(2000)` → no page reload |
| Consent grant ("Fehleranalyse" checked + saved) | Calls `Sentry.init(...)` guarded by `!Sentry.isInitialized()` → no page reload |

### Data Export (Settings Page)

| Trigger | Action |
|---------|--------|
| "Daten exportieren" button clicked | `POST /api/v1/export/request` → button shows spinner + "Wird erstellt…" + disabled |
| Poll interval (TanStack Query, 3s) while status=Generating | Shows "Wird erstellt…" status text with `Loader2` spinner |
| Status = Ready | Shows "Export bereit" + "Herunterladen" button (primary, emerald) |
| "Herunterladen" clicked | `GET /api/v1/export/download?token={token}` → browser download → token invalidated server-side |
| Status = Expired (re-fetch after 24h) | Shows expired copy + "Daten exportieren" button re-enabled |
| Error from POST or GET | `toast.error("Export fehlgeschlagen. Bitte erneut versuchen.")` via sonner |
| Container restart (token lost) | Next poll returns 404/Expired → shows expired state with re-request copy |

### Legal Pages

| Trigger | Action |
|---------|--------|
| Unauthenticated user navigates to `/agb` | Page loads (added to `PUBLIC_PATHS`) |
| Unauthenticated user navigates to `/widerruf` | Page loads (added to `PUBLIC_PATHS`) |
| User clicks any footer link | Navigate to route; `(legal)` pages use `(legal)/layout.tsx` |

## Accessibility Contracts

| Requirement | Implementation |
|-------------|---------------|
| Cookie banner keyboard-navigable | Tab order: banner heading → body → "Einstellungen" → "Nur notwendige" → "Alle akzeptieren" |
| "Notwendig" toggle must not be operable | `disabled` attribute on Checkbox + `aria-disabled="true"` |
| "Fehleranalyse" checkbox label association | `<label htmlFor="fehleranalyse-checkbox">` with matching `id` |
| Banner announces to screen readers | `role="region"` + `aria-label="Cookie-Einstellungen"` on banner wrapper |
| Consent dialog focus trap | shadcn `Dialog` provides focus trap natively via Radix |
| Equal prominence requirement (TTDSG) | Both "Alle akzeptieren" and "Nur notwendige" use the same height/size Button; no size or color dominance for one over the other (outline vs default differ in fill but not in size — acceptable per TTDSG guidance) |
| Export download action | `<a download>` or programmatic download — announced by screen reader as file download |

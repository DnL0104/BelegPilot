<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| handler/job → audit_log | Business-event writer; only the AuditLogger service writes rows |
| user deletion cascade → audit_log | Cascade must NOT reach audit rows; actor reference must survive |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-10 | Tampering | audit_log rows altered/deleted | mitigate | Append-only by code convention — AuditAppendOnlyTests structural-grep asserts zero Remove/RemoveRange/ExecuteDelete against AuditLogEntries anywhere in Application+Infrastructure |
| T-06-11 | Repudiation | Audit record lost when actor user is deleted | mitigate | No FK / no cascade on actor_user_id + subject_user_id (verified in EF config and migration acceptance_criteria); nullable actor column so row persists |
| T-06-12 | Information Disclosure | Raw PII (email, token) leaks into metadata jsonb | mitigate | DeleteAccountHandler stores SHA-256 email_hash not raw email; RefreshTokenService stores token_id_hash not raw token (Security Domain V9 / DSGVO Art. 5(1)(c)); acceptance_criteria grep-asserts no raw email/token in metadata |
| T-06-13 | Tampering | Cascade delete silently wired by EF convention | mitigate | EF config has no HasOne/WithMany for actor/subject; acceptance_criteria asserts absence of OnDelete(Cascade) + HasOne |
</threat_model>
